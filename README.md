# Financial-Sample-Data-Analysis
# 📊 Financial Data Analysis Dashboard | Power BI

## 📌 Project Overview

This project is an interactive *Financial Data Analysis Dashboard* created using *Microsoft Power BI*.

The dashboard provides insights into sales, profit, discounts, manufacturing price, sale price, units sold, products, countries, and yearly performance.

The objective of this project is to transform raw financial data into meaningful visual insights that can support data-driven decision making.

---

## 🎯 Objectives

- Analyze overall financial performance
- Understand sales and profit trends
- Compare product performance
- Analyze sales across different countries
- Examine discounts and pricing
- Analyze units sold by year
- Identify patterns in manufacturing and sale prices
- Create an interactive and easy-to-understand dashboard

---

## 🛠️ Tools & Technologies

- *Microsoft Power BI*
- *Power Query* – Data transformation and cleaning
- *DAX* – Calculations and measures
- *Data Visualization*
- *Microsoft Excel* – Data source

## 📊 Dashboard Visualizations

The dashboard contains the following visualizations:

### 1. Units Sold by Year
A pie chart showing the distribution of units sold across different years.

### 2. Manufacturing Price by Month
A funnel-style chart showing manufacturing price across different months.

### 3. Profit by Product
A column chart comparing profit generated by different products.

### 4. Discounts by Product
A doughnut chart showing the distribution of discounts across products.

### 5. Sale Price by Product
A pie chart comparing sale prices among different products.

### 6. Sales by Country
A column chart comparing total sales across different countries.
